Admin Panel

This page is a setup guide, not a secure login panel yet. Do not publish private admin credentials in website files. The real admin panel must use Supabase Authentication, database tables, and storage policies before it can safely upload reports or view membership requests.

01

Create Supabase project

Create a project, then add tables for reports, reviews, and membership requests. Keep the service-role key private and server-side only.

Open Supabase ↗
02

Set access rules

Enable Row Level Security. Public visitors may read approved reports/reviews; only your authenticated admin should create, update, or delete published content.

03

Connect the forms

Connect this site to Supabase using a public anon key with strict policies. Test the form, file uploads, and admin permissions before sharing the link.
